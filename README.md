# Takhoffman Homebrew Tap

This tap distributes [SSD Watcher](https://github.com/Takhoffman/ssd-watcher),
a native macOS menu-bar utility that watches agent databases for abnormal SSD
write activity.

## Install SSD Watcher

```sh
brew install --cask Takhoffman/tap/ssd-watcher
```

Homebrew uses the same command to upgrade it later:

```sh
brew upgrade --cask ssd-watcher
```

The Cask is published from SSD Watcher's signed and notarized release process.
